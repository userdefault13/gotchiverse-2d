# Store shelf placeholders (Modern Interiors Free)

Temporary art from LimeZu **Modern tiles / Modern Interiors** free pack
(`Interiors_free/16x16/Interiors_free_16x16.png`) so store furniture is easy to tell apart while building.

| Key | Source | Role |
|-----|--------|------|
| `feature_table` | Square wooden table (terracotta) | Feature Table 2×2 / 1 lg slot |
| `display_table` | Green-top desk | Display Table 2×2 / 4 sm slots |
| `rack_h` | 3-bay stocked shop shelf | Rack Horizontal 3×1 |
| `rack_v` | Tall wooden stocked shelf | Rack Vertical 1×3 |
| `holder_*` | Small props / mini tables | Slot overlays |
| `shelf` | Same as feature_table | Legacy alias |

Final Gotchiverse art comes later. Non-commercial free-pack license — see `Modern_tiles_Free_LICENSE.txt`.
